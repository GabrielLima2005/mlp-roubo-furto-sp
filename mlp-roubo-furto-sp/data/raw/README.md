# Dados brutos (não versionados)
Baixe a base escolhida em https://www.ssp.sp.gov.br/estatistica/consultas → *Bases de Dados*
(ex.: **Celulares Subtraídos**, um arquivo `.xlsx` por ano) e salve aqui. Registre no README principal o ano/período usado.
Se os nomes das colunas forem diferentes, ajuste `ALIASES` em `src/data_prep.py`.
